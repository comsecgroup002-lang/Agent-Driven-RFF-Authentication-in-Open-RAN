# Agent-Driven-RFF-Authentication-in-Open-RAN
An Agent-Driven Edge--Cloud Decision Framework for Radio-Frequency Fingerprint Authentication in Open Radio Access Networks

## Data Availability Statement

The LoRa experiments in this work are based on the publicly available OSU LoRa RF fingerprinting dataset cited in the manuscript. The 5G NR dataset was collected in a real-world commercial cellular environment and contains measurement data subject to confidentiality and data-use restrictions. Therefore, the raw 5G NR IQ recordings cannot be publicly released or redistributed. To support reproducibility despite this restriction, the manuscript provides detailed descriptions of the device population, acquisition configuration, session organization, sample scale, data partitioning, and evaluation protocol, while the accompanying repository provides the implementation and experimental workflow used in the study.
